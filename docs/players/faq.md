# Questions

**Isn't this just Waystones?**
No. Waystones teleports you. A stagecoach journey takes time, you can only set off from a coach, far stops may need a
change of coach on the way, and you can't leave right after being hit. Stagecoach is about the road.

**Why won't my coach place?**
It needs a clear space 3 wide, 3 tall and 6 long. Hold it and look at the ground: the red parts of the preview are
what's in the way, and the action bar says why. The full list is on [Your own stagecoach](coaches.md#placing).

**Why is a stop greyed out in my list?**
Hover over it. You can't afford the fare, it's in another dimension, it's too far for one trip, or the server has
closed it to you for now. See [Travelling](travelling.md#the-destination-list).

**A stop I know isn't in my list.**
The list never shows the stop you're standing at, and a server can hide stops from the list. A stop that was taken
down is gone from everyone's list.

**What happens if the game crashes while I'm on the road?**
Nothing is lost. When you come back you're where you set off, in your own game mode, with your fare returned.

**What if someone takes down the coach I'm travelling to?**
The journey is called off: you're set down where you left from and get your fare back.

**Can I travel to the Nether or the End?**
Not by default: coaches only run within one dimension. Servers can allow journeys between dimensions.

**Can other players break my coach?**
Not by default. Only you (and operators) can take your coach down, and explosions can't touch it.

**There's no coach in this village.**
Villages that existed before Stagecoach was installed have none. See [Village stops](villages.md#no-coach-in-your-village).

**Can I travel in creative?**
Yes, and for free.

**Does everyone need the mod?**
Yes: the server and every player who joins need the same Stagecoach file. A server and its players must run the same
version.

**I found a bug.**
Please report it on [GitHub](https://github.com/FelixForLyfe/Stagecoach/issues) or in the comments on CurseForge.
