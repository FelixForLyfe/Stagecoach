# Stagecoach

Stagecoach adds placeable stagecoaches in eleven woods and a road network between them. Every village has a coach
stop; players build the rest. Right-click a stop to discover it, then pay a fare (XP levels, or items) and ride the
road to any stop you know. A journey takes time: you watch the road roll past, and you arrive in front of the
destination coach. Everything is checked by the server and survives crashes.

This site is for players and for the people who build on it:

- **[Player guide](players/)** — how to craft and place a coach, discover stops, travel, the village stops, your
  options, and answers to common questions.
- **[Pack developer guide](pack/)** — modpack makers and server owners: every setting, command and permission
  node, coaches in your own structures, villages and natural generation, travel rules, advancements, travel scenes,
  and export and import. No code needed.
- **[Modder guide](modders/)** — other mods: the Java API, the events on every loader, and KubeJS.

Stagecoach runs on both sides: install the same file on the server and on every client. A server and its players
must run the same Stagecoach version (1.1.0 and 1.2.0 can't play together).

## What works with what

Every feature exists on all fourteen builds, except where the other mod doesn't exist for that Minecraft version:

| Mod | Builds |
|---|---|
| Open Parties and Claims, JourneyMap, Xaero's Minimap | all |
| FTB Chunks | 1.20.1 (Fabric, Forge), 1.21.1 (Fabric, NeoForge) |
| KubeJS | 1.20.1 (Fabric, Forge), 1.21.1 (NeoForge) |
| Game Stages (in travel rules) | 1.20.1 (Forge) |
| Jade | Fabric and NeoForge everywhere, Forge 1.20.1 |
| JEI | everywhere except Forge 1.21.11, 26.2 and 26.3 |
| TerraFirmaCraft recipes | Forge 1.20.1, NeoForge 1.21.1 |
| Mod Menu | Fabric |

None of them is required.
