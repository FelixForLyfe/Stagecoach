# Stagecoach 1.1.0 — what was decided, and how it was built

The 1.1.0 request (2026-10-11): follow the Linen code rules everywhere; longer routes, TerraFirmaCraft and item
fares as switchable options; fix 26.2's missing textures and its crash on Travel; a smoother, less AI-looking travel
screen with an option to skip it; more settings; port to the newest versions on Fabric, NeoForge and Forge; one big
changelog. Feelix answered the open questions and approved the 25 proposals below by not vetoing any.

## Answers

| Question | Answer |
|---|---|
| Ports | 26.3 on all three loaders; Forge for 1.21.1 and 26.2; 1.21.11 on all three loaders |
| Longer routes | Manual hops: `maxDistance`, farther stops greyed out as "too far" |
| No loading | Both: server `instantTravel` and client `minimalLoadingScreen` |
| Travel look | The 1.0.x road scene stays the default, made smoother; a route map on vanilla parchment is the client option `simplifiedLoadingScreen`, and `minimalLoadingScreen` (sign, bar, Cancel) wins over both |
| The 26.2 bug | Folded into 1.1.0 (no separate hotfix) |
| TFC | Recipes only, on the builds TFC exists for (Forge 1.20.1, NeoForge 1.21.1) |
| Paper plugin | Linen pass plus the matching server options; it keeps its road picture |
| Version | 1.1.0 everywhere |

## The 25 proposals

1. **Loader bridge kept**: `Platform` / `ClientPlatform` / `Registrar`.
2. **Names follow the mappings** (Yarn `world` on 1.20.1/1.21.1, Mojang `level` elsewhere). 1.21.11 is built from the
   26.2 code (Mojang names) rather than the 1.21.1 one.
3. **Forge and NeoForge register through `DeferredRegister`**: `Registrar#register(key, id, supplier)`; Fabric
   calls the supplier at once, the others hand it to a `DeferredRegister` per registry.
4. **No FILE/PURPOSE/CONTEXT headers** anywhere (scripts and properties keep the purpose as a plain comment).
5. **No allocation in hot paths**; ids and keys only through the registry classes and `MOD_ID`
   (`Stagecoach.id`, `Stagecoach.text`).
6. **Item fare**: `itemCostEnabled`, `costItem` (an id or `#tag`), `itemBaseCost` 1, `blocksPerItem` 1000,
   `maxItemCost` 32. It replaces XP while on.
7. **Refunds return the same items**: the paid stacks are kept in the journey record; inventory first, else dropped.
8. **Unknown `costItem` falls back to XP** with a log warning (`Fare.resolve`).
9. `maxDistance` (0 = off).
10. `instantTravel`.
11. **Client config** `config/stagecoach-client.json`: `simplifiedLoadingScreen`, `minimalLoadingScreen`,
    `showOtherStopsOnMap`, `showPlacementPreview`.
12. **Route map** (with `simplifiedLoadingScreen`): parchment of a size that's a multiple of 64 (max 320), a quadratic road between the stops with
    an arc-length table (`RoutePlot`), dots every 5 px, origin/destination banners from the vanilla map icons, the
    player marker, labels above the origin and below the destination, faint dots for other stops.
13. **TFC recipe**: PCP / LDL / DGD with TFC lumber, `#forge:chests/wooden` (`#c:chests/wooden` on 1.21.1), a
    lead, steel double sheets and a gold sheet; condition `stagecoach:tfc_recipes` (TFC loaded and `tfcRecipes`).
    Wood map: oak, spruce, birch, jungle → kapok, acacia, dark oak → blackwood, mangrove, cherry → rosewood,
    bamboo → palm. Crimson and warped keep the vanilla recipe.
14. `discoveryRequired`.
15. `maxCoachesPerPlayer` (operators exempt).
16. `useRange` (replaces the fixed 12 blocks).
17. `travelCooldownSeconds` (counted from arrival).
18. `cancelRefundPercent`: applies to Cancel only; every other early end refunds in full. The abandon screen and the
    end message say the percentage when it's below 100 (it rides in the journey-start packet).
19. `creativeTravelsFree`, `opsCanManageAnyCoach`.
20. `blockedDimensions` (placement only).
21. `maxNameLength` (1–64).
22. `/stagecoach reload` (permission level 2), which reports any warnings.
23. Client `showPlacementPreview`, and a config screen through Mod Menu and the Forge/NeoForge mod list.
24. Order of work: Linen pass and features on 1.20.1, port to 1.21.1 and 26.2, the new ports, verification, docs.
25. **1.1.0 on every jar**: one combined changelog plus one per uploaded file.

## How it ended up

- **Fourteen jars**: Fabric + Forge 1.20.1; Fabric + NeoForge + Forge on 1.21.1, 1.21.11, 26.2 and 26.3. The Paper
  plugin is its own 1.1.0 (its first release) with the same server options under the same names
  (`allowCrossWorld` / `blockedWorlds` for the dimension ones, the `stagecoach.admin` permission for
  `opsCanManageAnyCoach`).
- **Smoothness** comes from `TravelClock`: the client moves with real time, leans 5% a frame toward the server's
  clock, snaps when more than 40 ticks off, and never runs backwards.
- **Crash safety with items**: the journey record (with the paid stacks) reaches disk before anything is taken. On
  recovery, items come back only if the player's own file carried this journey's mirror — otherwise the server died
  before that file was saved, the file still holds the items, and returning them would double them. XP is always SET
  back, never added, so recovery is safe to replay.
- **The 26.2 bugs**: GeckoLib 5.5 reads models from `assets/<ns>/geckolib/models/` (the model is at
  `geckolib/models/block/stagecoach.geo.json`, id `stagecoach:block/stagecoach`); the Travel crash came from the
  travel screen's stand-in player, which had no entity id (26.x throws on `getId()` before one is set) — it gets
  `setId(-1)` now.

## Not done, on purpose

- FTB Chunks claims on 1.21.11 and 26.x: FTB Chunks has builds for 1.21.1 and 26.1.2 only.
- Jade and JEI on Forge 1.21.11 and 26.x (no Forge builds of them); Forge 1.21.1 has JEI.
- TFC on any other version: TFC is out for Forge 1.20.1 and NeoForge 1.21.1 only.
